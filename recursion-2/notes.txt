Just remember these three patterns:

Print all
console.log(ans);
return;

Count all
return include + exclude;

Find one
if(include) return true;
if(exclude) return true;
return false;



This is a major backtracking idea

You have now seen:

Normal recursion
Explore everything.
Pruned recursion
Stop exploring impossible branches.

Combination Sum

Sudoku

almost everywhere.
